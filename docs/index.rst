School Management System
========================

**Lab 4 — Git and GitHub | EECE 435L — Software Tools Laboratory**

:Author: Tatiana Kaado
:Version: |release|
:Copyright: 2026, Tatiana Kaado

This project combines the **Tkinter and PyQt5 interfaces** using shared
object-oriented models and SQLite persistence. The PyQt5 and backend API pages
retain the Sphinx-style docstrings from Lab 3.

The dashboard manages students, instructors, courses, and enrollments. It
provides validated forms, search, editing, deletion, JSON import/export,
CSV export, and database backup/restore.
